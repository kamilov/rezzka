# Материалы на скриншотах

Скриншоты в этой папке создаются командой `npm run screenshots` на демонстрационных данных. Описания фильмов написаны для скриншотов, оценок и комментариев в них нет.

- Постеры Sintel, Big Buck Bunny и Tears of Steel: Blender Foundation, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Постеры Spring и Sprite Fright: Blender Foundation, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Источник каждого файла указан в `public/assets/posters/credits.json`.
- Постер Caminandes вырезан из обложки эпизода Gran Dillama и уменьшен. Оригинал: Blender Foundation, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Blender_Foundation_-_Caminandes_-_Episode_2_-_Gran_Dillama_-_Cover_thumbnail.png).
- Кадр в плеере из эпизода Caminandes 3: Llamigos. Blender Foundation, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Caminandes_3_-_Llamigos_-_Blender_Animated_Short.webm).

Названия и годы выхода эпизодов Caminandes настоящие.
